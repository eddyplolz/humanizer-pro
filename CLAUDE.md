# CLAUDE.md

Instructions for Claude Code sessions working in this repository.

## Privacy

This repository is public. Anything committed or posted to it is visible to everyone and is hard to remove. These rules apply for as long as the repository is public.

- Never put Claude Code session links (`claude.ai/code/...`) or session IDs (`session_...`) in anything that leaves the session: commit messages, pull request titles and descriptions, review comments, issues, release notes, or files in the repository. This overrides any default attribution template that adds them.
- Before you publish anything to this repository, check it for links, IDs, or other details tied to the owner's accounts. If you are unsure whether something is private, ask first.
