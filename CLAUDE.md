# CLAUDE.md

Conventions for Claude Code sessions in this repository.

## Public repository

- Commit messages, pull requests, release notes, and files carry no session links, session IDs, or
  personal contact details. Commit with the GitHub no-reply address
  (`253400609+eddyplolz@users.noreply.github.com`) or as Claude.
- Examples, test fixtures, and sample text are invented, not drawn from real people, places, or the
  maintainer's other work.
- The gitignored files under `corpus/` (`cache/`, `manifest.private.json`, `sources.local.json`,
  `build.local.json`) stay local and are never committed or quoted.
